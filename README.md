# おにぎりころがり

20秒で具材を集めて、今日のおにぎりを作るミニゲームです。
完成したおにぎりの名前、ランク、今日の一言を楽しめます。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「ころがる」を押してゲームを始めます。
3. スペースキー、上矢印キー、または「はねる」ボタンでジャンプします。

二段ジャンプもできます。具材を集めながら、落とし穴を避けておうちを目指してください。

## ファイル構成

- `index.html`: 画面とスタイル
- `script.js`: ゲーム処理
- `assets/`: 画像、BGM、効果音
- `scripts/`: BGM生成用スクリプト
